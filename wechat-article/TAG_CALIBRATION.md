# 揽宝投研 · 标签校准清单

> 目的：解决「关注无关公众号 → 兴趣标签错乱 → 推荐流量不精准 → 完读率低」的问题。
> 本清单覆盖两部分：**A. 账号行为校准（需人工在微信执行）** 与 **B. 内容标签校准（已落地为脚本，自动检查）**。

---

## A. 账号行为校准（人工，微信端执行）

微信不开放「取关/关注列表」API，这部分必须在手机或 PC 端手动完成。一次性做，之后每周复核一次。

- [ ] 取关所有与「A股 / 投研 / 复盘 / 量化」无关的公众号（美食、宠物、游戏、八卦、带货等）
- [ ] 不再参与「互关、互推、回流」涨粉——脏粉拉低完读率，是负资产
- [ ] 主动关注 5–10 个同赛道账号（财经、复盘、情绪周期、涨停研究），用于校准系统对你兴趣的识别
- [ ] 对同赛道优质文章点「在看」、完整读完、留言——强化「财经深度读者」行为标签
- [ ] 每周查看后台「用户画像 → 兴趣标签」，确认回归财经/股票/投资

> 判断恢复的信号：完读率回升 **先于** 粉丝数回升。连续发 3–5 篇垂直内容后观察。

## B. 内容标签校准（自动，`tag_calibration_check.py`）

每篇文章发布前必须通过检查。脚本读取 `article.md`，逐项打分（满分 100，≥80 且无 ERROR 才放行）。

### B1. 核心关键词垂直度（30 分）
系统靠正文关键词识别账号领域。要求前 300 字内出现 ≥3 个核心词，全文核心词总频次 ≥8。

核心词表（A股短线投研）：
`A股 / 复盘 / 涨停 / 情绪 / 晋级率 / 连板 / 跌停 / 上涨占比 / 昨日涨停 / 赚钱效应 / 亏钱效应 / 资金 / 档位 / 首板 / 中位表现 / 明日验证`

**无关领域词命中即扣分**（美食、宠物、游戏、美妆、育儿、星座、带货…）：出现一个扣 10 分并标记 ERROR。

### B2. 真实数据对照区块（25 分）
每篇必带「同一指标、两种结果」的对照，这是你的差异化钩子，直接拉完读率。

- 含「真实数据对照」小标题（+8）
- 含两组带单位的数字读数，如 `+4.60%` / `-0.45%`（+8）
- 含来源标注「来自揽宝投研当日复盘原文 / 程序对公开数据逐项核对」（+5）
- 含「档位是分析框架，不是客观事实」（+4）

### B3. 标题质量（15 分）
- 20 字以内（+5）
- 核心词前置（前 12 字含核心词）（+6）
- 无震惊体（"震惊/必看/不看后悔/暴跌惊人"等，命中扣 15 并 ERROR）（+4）

### B4. 文末结构（15 分）
固定三段落，顺序与样式固定，形成品牌辨识度：
- 加粗互动提问（+5）
- 斜体话题标签，5 个且含核心词（+5）
- 引用块「**风险警示：**」+ 完整免责（+5）

### B5. 配置一致性（15 分）
- `source_url: https://ten2net.github.io/`（+4）—— 阅读原文只到博客首页
- `cover: ./cover.png` 且文件存在（+4）
- `collection` 存在（+3）
- 无违规结尾词（点赞/在看/转发 等诱导语，命中扣 10 并 ERROR）（+4）

> 注：诱导「点在看/转发」虽能拿推荐，但被微信判违规风险高；本清单采用**内容质量驱动**，不写这类词。

## 使用方法

```bash
# 检查单篇
.venv/bin/python wechat-article/tag_calibration_check.py wechat-article/output/2026-11-23-series/01/article.md

# 检查整个 series 目录（逐篇输出）
.venv/bin/python wechat-article/tag_calibration_check.py wechat-article/output/2026-11-23-series

# 不通过时返回码 1，可接入发布前钩子
```

退出码：`0` = 通过，`1` = 未通过。ERROR 项会直接阻止放行。

## 发布前拦截接入（已实施）

两条发布链路都已接入，未通过则**发布被阻止**：

### 链路 1：skill 发系列文章（`wxpub publish`）

- 钩子脚本：`wechat-article/tag_calibration_check.py`（需可执行位，已 `chmod +x`）
- 配置：`.wxpub/.env` 的 `WXPUB_TAG_CHECK=<脚本绝对路径>`
- 接入点：`pipeline.mjs` 的 `inspectPackage` 之后、任何上传之前
- 关闭：删除/留空 `WXPUB_TAG_CHECK`
- **skill 升级后钩子会丢失**，用 `node wechat-article/patch_wxpub_tag_gate.mjs` 重新应用（幂等）

### 链路 2：复盘自动发布（`scripts/wechat_daily.py`）

- 接入点：`review_agent/wechat_publish.py` 的 `publish_review()`，在 `article_html()` 之后、微信 API 之前
- 检查正文 HTML（去标签后）的核心词密度、污染词、标题质量
- 关闭：`ASTOCK_TAG_GATE=0`

### 验证结果

- skill 链路：01 篇（100 分）通过；污染文章（-99 分）被拦截，退出码 1
- 复盘链路：`check_text()` 模拟复盘正文通过，语法校验通过
