# 创作者素材包(creator-pack)

商业化 B(自媒体素材服务)的交付物。每个交易日盘后由 `scripts/export-pack.mjs`
自动生成,放在 `.local/creator-pack/<日期>/`(私有层,不进仓库):

| 文件 | 用途 |
|---|---|
| `pack.md` | 人类可读:三个板块排好版,直接当选题底稿改写成内容 |
| `pack.json` | 结构化全量:各视图原始字段原样保留,供程序二次加工(图表/自动播报) |

## 内容(全部程序计算的客观读数)

1. **分时资金 · 横盘后拉升榜**(`shortline_fflow`):当日分钟资金「先横盘、后稳步拉升」的前 20 只,
   含主力净流入、横盘/拉升时长、拉升幅度、稳步度、数据来源通道与截至时间。
2. **近 5 天短线热度与龙头**(`shortline_weekly`):每日涨停家数、最高板、炸板率、领头股(带板位)。
3. **涨停结构变化**(`shortline_structure`):近 5 天 vs 之前窗口的结构迁移摘要与异动项。

生成命令(容器内,建议 15:40 后由宿主机 cron 触发):

```bash
docker exec vibe-astock-v2 node /app/scripts/export-pack.mjs
```

## 合作模式(建议)

- **冷启动期(第 1-2 个月)**:免费给 5-10 个做涨停复盘/短线观察的中小创作者供素材,
  只要求署名「数据来源:揽宝投研」+ 挂产品链接 —— 他们成为你的分发渠道(生态寄生)。
- **验证期**:观察回流(链接点击、产品访问)。素材若真省创作者时间,会出现主动续用与转介绍;
  此时再谈付费素材 API(月度订阅)或白标。
- **收费点永远不在"观点"上**:素材是客观读数整理,不输出买卖建议(产品本身的合规闸也守这条线)。

## 二次发布红线(也印在每份 pack 的条款页脚)

1. 不得改写成买卖建议、目标价、收益承诺;必须保留「非推荐、非预测」声明。
2. 必须保留署名与素材生成日期;数据截至时间以各视图标注为准,不得把旧数据当新数据发。
3. `pack.json` 仅限创作者本人账号加工,不得原样再分发。
